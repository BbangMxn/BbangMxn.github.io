## 글 작성

프로젝트는 `content/projects/`, 공부한 내용은 `content/notes/`에 작성합니다. 해커톤은 `projects/hackathon/`, 캡스톤은 `projects/capstone/`에 모읍니다.

메인은 디자인된 소개 화면으로, 나머지 문서는 공통 Markdown 화면으로 읽습니다. 제목·본문·표·코드·이미지·목차를 사용할 수 있습니다.

프로젝트에는 실제 적용한 내용과 선택 이유를 적고, 개념 설명은 관련 공부 노트로 연결합니다. 필요한 내용이 생겼을 때 문서를 추가하면 됩니다.
