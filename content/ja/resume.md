# バックエンドエンジニア

日本でのバックエンドエンジニア就職を目指しています。個人プロジェクトを中心に、API、データモデル、検索システムの設計・実装・検証に取り組んでいます。

## 技術

- Java / Spring Boot — 検索サーバーとRAG実験
- Rust / PostgreSQL / Redis — 機材ドメインのAPI・データモデル・キャッシュ
- OPC UA / MQTT / TimescaleDB — 製造データ基盤の研究・設計

## 主なプロジェクト

### [Nazgul](/ja/projects/nazgul)

趣味データの検索から回答の根拠までをつなぐ処理フローを設計。Javaサーバー、ローカルAIの実験、検証ドキュメントを担当しました。

研究プロトタイプ · 検索フローを検証、定量評価は今後拡充。

### [BagInDB](/ja/projects/bagindb)

機材・ブランドのデータを独立したドメインに分離。API、データモデル、Redisキャッシュ、JWT検証を実装しました。

個人プロジェクト · キャッシュ無効化と運用方針を改善中。

### [Smart Factory](/ja/projects/smartfactory)

設備データの収集、時系列保存、リアルタイム配信をつなぐ構成を研究し、プロトタイプの実装方針を設計しました。

研究・プロトタイプ · 実運用および大規模な性能検証は未実施。
