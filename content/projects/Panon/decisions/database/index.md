DB 제품 선택과 데이터 모델 변경의 흐름을 기록합니다. 현재 상태는 [현재 DB 구조](../../architecture/database.md)에서 확인합니다.

## 변경 내역

아래 세 문서는 작성 틀입니다. 실제 변경 횟수나 시간 순서를 확정한 기록이 아니며, 이력을 확인한 뒤 제목·날짜·순서를 조정합니다.

| [002 구조 변경](./002-구조-변경.md) | 작성 예정 | 미확인 | 미확인 | 미확인 |

## 변경 유형

| 유형 | 기록할 내용 |
| --- | --- |
| DB 제품 변경 | DB 엔진이나 제품을 선택·교체한 이유 |
| 스키마·모델 변경 | 테이블, 관계, JSON, 식별자 등의 설계 변경 |
| 저장소 역할 변경 | 검색·캐시·원본 저장소 등의 책임 변경 |

## 읽는 방법

변경 전 문제 → 검토한 대안 → 선택 → 적용 과정 순서로 읽습니다. 코드에 반영한 시점과 실제 데이터를 이전하거나 운영에 적용한 시점은 따로 기록합니다.
